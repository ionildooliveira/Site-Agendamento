# Database and Migrations Skill

Esta skill documenta a estrutura de dados relacional e a sequência cronológica de migrações executadas no Supabase PostgreSQL.

## 1. Histórico de Migrações SQL

1. `supabase_schema.sql`: Esquema original em PostgreSQL contendo tabelas individuais para um único salão (`admin_users`, `clients`, `professionals`, `services`, `bookings`, `settings`, `blocked_dates`).
2. `01_multitenant_migration.sql`:
   - Criação da tabela `companies` com identificadores UUID.
   - Adição da coluna `company_id` em todas as tabelas.
   - Migração e consolidação das configurações de salão para o campo `salon_data` (JSONB) dentro de `settings`.
3. `02_fix_client_email_unique.sql`:
   - Removeu a unicidade global de e-mails em clientes.
   - Adicionou a constraint combinada `UNIQUE(email, company_id)`, permitindo que um mesmo cliente frequente múltiplos salões na plataforma.
4. `03_add_salon_data_to_settings.sql`:
   - Ajuste de colunas JSONB para metadados de marketing e identidade do salão.
5. `04_create_testimonials.sql`:
   - Criação da tabela `testimonials` com moderação (`pending`, `approved`, `rejected`) e notas de 1 a 5.
6. `05_company_management.sql`:
   - Adição da coluna `is_active` na tabela `companies`.
   - Atualização de todas as chaves estrangeiras com a regra **`ON DELETE CASCADE`** para garantia de exclusão atômica.
7. `06_create_gallery.sql`:
   - Criação da tabela `gallery_images` com links para o Supabase Storage.
8. `07_create_subscriptions.sql`:
   - Criação da tabela `subscriptions` com suporte a pagamentos Mercado Pago, ciclos de faturamento mensais, cobranças automáticas e histórico de status.

## 2. DDL Consolidado do Banco de Dados

```sql
-- 1. Empresas (Tenants)
CREATE TABLE companies (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  name TEXT NOT NULL,
  slug TEXT UNIQUE NOT NULL,
  is_active BOOLEAN DEFAULT TRUE,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- 2. Administradores da Loja
CREATE TABLE admin_users (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  company_id UUID NOT NULL REFERENCES companies(id) ON DELETE CASCADE,
  name TEXT NOT NULL,
  email TEXT UNIQUE NOT NULL,
  password_hash TEXT NOT NULL,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now()) NOT NULL
);

-- 3. Clientes
CREATE TABLE clients (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  company_id UUID NOT NULL REFERENCES companies(id) ON DELETE CASCADE,
  name TEXT NOT NULL,
  phone TEXT NOT NULL,
  email TEXT NOT NULL,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now()) NOT NULL,
  UNIQUE(email, company_id)
);

-- 4. Profissionais
CREATE TABLE professionals (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  company_id UUID NOT NULL REFERENCES companies(id) ON DELETE CASCADE,
  name TEXT NOT NULL,
  role TEXT NOT NULL,
  bio TEXT,
  photo_url TEXT,
  specialties JSONB DEFAULT '[]'::jsonb,
  active BOOLEAN DEFAULT true
);

-- 5. Catálogo de Serviços
CREATE TABLE services (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  company_id UUID NOT NULL REFERENCES companies(id) ON DELETE CASCADE,
  name TEXT NOT NULL,
  description TEXT,
  price NUMERIC(10, 2) NOT NULL,
  duration_minutes INTEGER NOT NULL,
  category TEXT,
  active BOOLEAN DEFAULT true
);

-- 6. Agendamentos
CREATE TABLE bookings (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  company_id UUID NOT NULL REFERENCES companies(id) ON DELETE CASCADE,
  client_id BIGINT REFERENCES clients(id) ON DELETE CASCADE,
  professional_id BIGINT REFERENCES professionals(id) ON DELETE SET NULL,
  service_id BIGINT REFERENCES services(id) ON DELETE SET NULL,
  booking_date DATE NOT NULL,
  start_time TIME NOT NULL,
  end_time TIME NOT NULL,
  status TEXT DEFAULT 'confirmed',
  notes TEXT,
  cancel_token TEXT,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now()) NOT NULL
);

-- 7. Configurações e Expediente
CREATE TABLE settings (
  id BIGINT PRIMARY KEY DEFAULT 1,
  company_id UUID NOT NULL REFERENCES companies(id) ON DELETE CASCADE,
  working_hours JSONB NOT NULL DEFAULT '{"0":null,"1":{"open":"09:00","close":"19:00"},"2":{"open":"09:00","close":"19:00"},"3":{"open":"09:00","close":"19:00"},"4":{"open":"09:00","close":"19:00"},"5":{"open":"09:00","close":"19:00"},"6":{"open":"09:00","close":"17:00"}}'::jsonb,
  slot_interval INTEGER DEFAULT 30,
  salon_data JSONB DEFAULT '{}'::jsonb
);

-- 8. Datas Bloqueadas
CREATE TABLE blocked_dates (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  company_id UUID NOT NULL REFERENCES companies(id) ON DELETE CASCADE,
  date DATE NOT NULL,
  reason TEXT,
  professional_id BIGINT REFERENCES professionals(id) ON DELETE CASCADE
);

-- 9. Depoimentos e Avaliações
CREATE TABLE testimonials (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  company_id UUID NOT NULL REFERENCES companies(id) ON DELETE CASCADE,
  client_id BIGINT REFERENCES clients(id) ON DELETE CASCADE,
  booking_id BIGINT REFERENCES bookings(id) ON DELETE CASCADE,
  rating INTEGER NOT NULL CHECK (rating >= 1 AND rating <= 5),
  comment TEXT NOT NULL,
  status TEXT DEFAULT 'pending' CHECK (status IN ('pending', 'approved', 'rejected')),
  created_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now()) NOT NULL
);

-- 10. Galeria de Fotos
CREATE TABLE gallery_images (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  company_id TEXT NOT NULL,
  image_url TEXT NOT NULL,
  title TEXT,
  description TEXT,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now()) NOT NULL
);

-- 11. Assinaturas e Pagamentos Recorrentes (Mercado Pago)
CREATE TABLE subscriptions (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  company_id UUID REFERENCES companies(id) ON DELETE CASCADE,
  user_email TEXT NOT NULL,
  user_name TEXT,
  user_cpf TEXT,
  user_phone TEXT,
  plan_name TEXT DEFAULT 'Plano Profissional',
  amount NUMERIC(10, 2) NOT NULL DEFAULT 49.90,
  billing_cycle TEXT DEFAULT 'monthly',
  payment_method TEXT NOT NULL,
  payment_status TEXT NOT NULL DEFAULT 'approved',
  auto_recurring BOOLEAN DEFAULT TRUE,
  mp_payment_id TEXT,
  mp_preapproval_id TEXT,
  mp_status TEXT,
  mp_qr_code TEXT,
  mp_qr_code_base64 TEXT,
  current_period_start TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
  current_period_end TIMESTAMP WITH TIME ZONE DEFAULT (NOW() + INTERVAL '30 days'),
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
  updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
```
